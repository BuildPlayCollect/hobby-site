---
title: Group buy
hobby: keyboards
summary: A pre-order where fans pay up front so a keyboard or keycap set can be made in one production run.
aliases: [group buy, group buys, Group buys]
---
In a group buy, a designer shows renders of a keyboard or keycap set, and vendors in each region take orders for a set window of time. Once the window closes, the order goes to the factory. Production takes months, so the "ETA" in a group buy post is an estimate, not a promise. If too few people join, a group buy can be cancelled and refunded.
